# Ninebot Control

Android-приложение (Kotlin + Jetpack Compose) для подключения по BLE к
Ninebot Max Plus SNSC: выбор режима скорости (1/2/3), блокировка движения,
приборная панель (скорость, мощность, батарея, пробег) и Demo-Mode для
просмотра функционала без подключения к самокату.

## Вкладки

- **Подключение** — поиск BLE-устройств, подключение/отключение, журнал
  сырых пакетов (hex) для отладки.
- **Управление** — выбор режима скорости (1/2/3) и переключатель блокировки
  движения.
- **Панель** — спидометр и карточки категорий: Скорость, Мощность, Батарея,
  Пробег, с цветовой индикацией зон (эко/норма/спорт).
- **Тюнинг** — лимит тока, override максимальной скорости и field weakening.
  Работает только с контроллерами на кастомной прошивке (DRV и аналоги) —
  заводская/шеринговая прошивка эти регистры не поддерживает и просто не
  ответит на них.
- **Demo-Mode** — приборная панель, управление и тюнинг на симулированных
  данных, без реального подключения. Удобно, чтобы посмотреть интерфейс
  заранее.

## Важно про протокол

BLE-протокол Ninebot не является официально документированным. Кадрирование
пакетов в `NinebotProtocol.kt` реализовано по общей схеме, известной
сообществу для линейки Ninebot/Xiaomi M365-ES-Max (заголовок `5A A5`, длина,
адреса, команда, регистр, payload, контрольная сумма). Конкретные адреса
регистров для режима скорости и блокировки движения (в `UnverifiedRegisters`)
— это **плейсхолдеры**, не подтверждённые на реальном SNSC-устройстве.

Перед боевым использованием:

1. Подключитесь на вкладке «Подключение» и посмотрите журнал обмена.
2. Сверьте реальные пакеты (например, параллельно наблюдая трафик из
   официального приложения) с тем, что ожидает `NinebotProtocol`.
3. При необходимости скорректируйте значения регистров в
   `NinebotProtocol.UnverifiedRegisters`.

**Управление крышкой деки намеренно не реализовано.** Для шеринговых моделей
этот замок относится к сервисной/антивандальной части, обычно управляемой
бэкендом оператора флота, а не личным BLE-подключением — соответствующий
функционал в приложение не добавлялся.

Вкладка «Тюнинг» (регистры `TUNING_*` в `UnverifiedRegisters`) рассчитана на
личные самокаты с установленной кастомной прошивкой контроллера (DRV и
подобные открытые прошивки для тюнинга тока/скорости), а не на снятие
ограничений заводской/шеринговой прошивки — на ней эти регистры отсутствуют.

## Сборка APK

Сборка происходит автоматически через GitHub Actions
(`.github/workflows/build.yml`) при пуше в `main`/`master` или вручную через
"Run workflow". Готовый `app-debug.apk` появляется в разделе **Actions →
выбранный запуск → Artifacts**.

Локально (при наличии Android SDK):

```bash
./gradlew assembleDebug
```
