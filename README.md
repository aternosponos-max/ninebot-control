# Ninebot Control

Android-приложение (Kotlin + Jetpack Compose) для подключения по BLE к
Ninebot Max Plus SNSC: выбор режима скорости (1/2/3), блокировка движения,
приборная панель (скорость, мощность, батарея, пробег) и Demo-Mode для
просмотра функционала без подключения к самокату.

## Вкладки

- **Подключение** — поиск BLE-устройств, подключение/отключение, журнал
  сырых пакетов (hex) для отладки.
- **Управление** — выбор режима скорости (1/2/3) и переключатель блокировки
  движения.
- **Панель** — спидометр и карточки категорий: Скорость, Мощность, Батарея,
  Пробег, с цветовой индикацией зон (эко/норма/спорт).
- **Тюнинг** — фазный и батарейный ток (до 120 А — см. предупреждение ниже),
  override максимальной скорости, ток рекуперации, брейк буст, буст на газ,
  буст на разгон, field weakening, круиз-контроль и переключение профилей
  прошивки (Эко/Комфорт/Спорт/Свой — выбор профиля применяет пресет ко всем
  параметрам разом). Работает только с контроллерами на кастомной прошивке
  (DRV и аналоги) — заводская/шеринговая прошивка эти регистры не
  поддерживает и просто не ответит на них.
- **Статистика** — диагностика в духе сторонних дашборд-приложений
  (Ninedash и подобных): напряжение по каждой ячейке батареи и разброс между
  ними, коды ошибок контроллера, версия прошивки и серийный номер, время
  поездки, средняя и максимальная скорость за сессию.

Через меню «⋮» в правом верхнем углу главного экрана также доступны:

- **Demo-Mode** — приборная панель, управление, тюнинг и статистика на
  симулированных данных, без реального подключения. Удобно, чтобы посмотреть
  интерфейс заранее.
- **Авторы** — контакты: Telegram [@besoro](https://t.me/besoro), TikTok
  [am0k102](https://www.tiktok.com/@am0k102).

## Важно про протокол

BLE-протокол Ninebot не является официально документированным. Кадрирование
пакетов в `NinebotProtocol.kt` реализовано по общей схеме, известной
сообществу для линейки Ninebot/Xiaomi M365-ES-Max (заголовок `5A A5`, длина,
адреса, команда, регистр, payload, контрольная сумма). Конкретные адреса
регистров для режима скорости и блокировки движения (в `UnverifiedRegisters`)
— это **плейсхолдеры**, не подтверждённые на реальном SNSC-устройстве.

Перед боевым использованием:

1. Подключитесь на вкладке «Подключение» и посмотрите журнал обмена.
2. Сверьте реальные пакеты (например, параллельно наблюдая трафик из
   официального приложения) с тем, что ожидает `NinebotProtocol`.
3. При необходимости скорректируйте значения регистров в
   `NinebotProtocol.UnverifiedRegisters`.

**Управление крышкой деки намеренно не реализовано.** Для шеринговых моделей
этот замок относится к сервисной/антивандальной части, обычно управляемой
бэкендом оператора флота, а не личным BLE-подключением — соответствующий
функционал в приложение не добавлялся.

Вкладка «Тюнинг» (регистры `TUNING_*` в `UnverifiedRegisters`) рассчитана на
личные самокаты с установленной кастомной прошивкой контроллера (DRV и
подобные открытые прошивки для тюнинга тока/скорости), а не на снятие
ограничений заводской/шеринговой прошивки — на ней эти регистры отсутствуют.

**О верхнем пределе тока (120 А).** По явному запросу владельца верхние
границы фазного, батарейного тока и тока рекуперации подняты до 120 А под
усиленный контроллер. Это заметно выше типичных значений даже для
доработанных прошивок в этой линейке (сообщество обычно держится в районе
40–60 А даже на модифицированном железе) — ответственность за соответствие
этих значений реальным возможностям конкретного контроллера лежит на
владельце устройства. Поднимайте ток постепенно и контролируйте температуру
мотора, контроллера и батареи — само приложение физических ограничений не
проверяет.

Вкладка «Статистика» (регистры `DIAG_*`) читает диагностический блок через
`requestDiagnostics()`. Разбор содержимого ответа под конкретную прошивку не
реализован до калибровки по реальному устройству — сырой ответ будет виден в
журнале на вкладке «Подключение», как и для остальных команд. Прошивка
самоката для чтения прошивки/серийника отдаёт то, что поддерживает; на
заводской/шеринговой прошивке часть полей (ячейки, ошибки) может быть
недоступна или возвращать нули.

**Намеренно не реализовано:** прошивка/перепрошивка контроллера по BLE. Это
отдельная, более рискованная операция (риск "кирпича" устройства), вне
задачи этого приложения — используйте для неё специализированные инструменты
сообщества (ScooterHacking Utility и подобные), а это приложение — как панель
управления и диагностики после того, как кастомная прошивка уже установлена.

## Сборка APK

Сборка происходит автоматически через GitHub Actions
(`.github/workflows/build.yml`) при пуше в `main`/`master` или вручную через
"Run workflow". Готовый `app-debug.apk` появляется в разделе **Actions →
выбранный запуск → Artifacts**.

Локально (при наличии Android SDK):

```bash
./gradlew assembleDebug
```
